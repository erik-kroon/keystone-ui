# 0.1 Preview Release Checklist

## Status

Draft checklist for private or public 0.1 preview readiness.

## Release Posture

- [ ] Decide whether the preview is private or public.
- [ ] Decide final package scope, names, and version posture.
- [ ] Confirm Keystone and Mason codename posture for release materials.
- [ ] Confirm MIT license copyright wording.
- [ ] Keep primitive breadth frozen for the preview.

## Keystone Docs And Specs

- [x] Primitive metadata includes maturity labels.
- [x] Keystone/Mason boundary docs page exists.
- [x] `data-scope`/`data-part` contract docs page exists.
- [x] Overlay kernel boundary note exists.
- [x] Collection/typeahead kernel boundary note exists.
- [x] Dialog accessibility spec exists.
- [x] Select accessibility spec exists.
- [x] Field/FormControl accessibility spec exists.
- [ ] Add manual accessibility evidence for stable candidates.
- [ ] Decide whether any beta primitive can be called stable in the preview.

## Mason Docs And Registry

- [x] Mason registry lifecycle docs exist.
- [x] Default local-registry preview behavior is documented.
- [x] Registry parity metadata is documented.
- [ ] Surface lifecycle docs in the docs app before public preview.
- [ ] Decide hosted default registry timing.

## Verification

- [ ] Run `bun install` if lockfile or dependencies changed.
- [ ] Run `bun run check`.
- [ ] Run `bun run check-types`.
- [ ] Run `bun run verify:release`.
- [ ] Record command results and date in release notes.

## Before Tagging Or Sharing

- [ ] Update `docs/releases/0.1.0-preview.md` with final posture.
- [ ] Update `docs/reports/0.1-preview-readiness-tracker.md` statuses.
- [ ] Confirm root `README.md` remains external-facing and does not duplicate internal roadmap detail.
- [ ] Confirm package manifests match the chosen preview posture.
- [ ] Confirm no Mason item lacks `meta.parity` notes.
- [ ] Confirm no Keystone public primitive lacks docs metadata for parts and maturity.
