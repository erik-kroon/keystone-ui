# 0.1.0 Preview Release Notes

## Status

Draft private preview notes. Generated 2026-05-04 from the current repo state.

This private preview is for Keystone/Mason convergence and selected early evaluation. It is not a stable public release.

## Release Posture

- Packages remain private `0.0.0` for this preview.
- `Keystone` and `Mason` remain working product names until naming, trademark, domain, and handle clearance are complete.
- `@keystone-ui` remains the provisional internal package scope for private preview work.
- Source is licensed under MIT via the root `LICENSE` file.
- Primitive breadth is frozen for the preview. New work should harden existing kernels, docs, specs, accessibility evidence, and Mason lifecycle behavior.

## What Is In This Preview

### Keystone

- Headless Solid primitive package with subpath exports for current preview primitives and utilities.
- Deep private kernels for controllable state, event composition, IDs, polymorphic rendering, overlay layering, focus scope, dismissable layers, prevent scroll, outside hiding, presence, floating geometry, collection registration, typeahead, list navigation, selection, and form-control behavior.
- Current strongest user-facing proof surfaces: Dialog, Select, Field/FormControl, overlays, collection/menu primitives, Tabs, selection controls, Slider, DatePicker/Calendar, Toast, and helper utilities.
- Docs metadata for primitive parts, `data-scope`, `data-part`, state attributes, CSS variables, SSR notes, and conservative maturity labels.

### Mason

- Local first-party registry with 37 item metadata files and parity notes.
- Registry validation for item schema, file targets, dependency graphs, path safety, duplicate targets, dependency specifiers, and parity metadata.
- CLI preview for `init`, `add`, `diff`, `update`, `remove`, and `doctor`.
- Generated-app verification for representative registry installs.
- TanStack-backed app-layer proof through DataTable, router-aware table state, TextField, SelectField, and CommandMenu metadata/source.

## Known Preview Limitations

### Product / Release

- Public package scope and final naming are undecided.
- Packages are not prepared for npm publication.
- Public-facing installation docs are not final.

### Keystone

- Most primitives are beta or experimental, not stable.
- Private kernels are intentionally not public API.
- Stable-candidate accessibility specs are still being written.
- Manual assistive-technology evidence is not complete.
- Public Listbox remains internal until Select and Combobox APIs settle.

### Mason

- `mason add`, `diff`, and `update` require an explicit `--registry <path>` in this preview.
- No hosted default registry is published yet.
- Lifecycle commands are tested but still need broader user-facing docs and preview UX polish.
- Generated-app verification covers representative Vite Solid fixtures, not every SolidStart, router, style, or monorepo shape.

## Do Not Expand For 0.1

Do not start RealtimeTable, Watchlist, TerminalLayout, ConditionBuilder, EventFeed, NumberField, DateRangePicker, color primitives, Drawer gestures, ScrollArea, or a Keystone Command primitive for this preview.
