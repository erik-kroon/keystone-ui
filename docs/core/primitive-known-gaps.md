# Core Primitive Known Gaps

## Purpose

This page documents the visible gaps for beta and experimental Core primitives. It separates API/product gaps from browser and manual assistive-technology evidence so preview docs do not imply stable parity before the evidence exists.

Stable status requires the maturity-model bar in `docs/roadmap/maturity-model.md`: stable API, documented ARIA and keyboard behavior, SSR/hydration smoke coverage where relevant, stable `data-scope`/`data-part` anatomy, CSS variable contracts for measured parts, and accessibility evidence for complex primitives.

Overlay derivative interaction evidence for Popover and Tooltip is tracked in [Overlay Interaction Matrices](overlay-interaction-matrices.md).

## Internal Surfaces

`listbox` and `overlay` are internal metadata scopes. Their gaps are tracked through the public primitives that consume them. Do not use this page to promote private kernels into public API.

## Menu Family Notes

`menu`, `dropdown-menu`, `context-menu`, `menubar`, and `navigation-menu` intentionally remain experimental. The current shared kernel covers item registration, typeahead, checked/radio item state, submenus, floating content, and scoped `data-*` anatomy, but menubar and navigation menu are still scoped menu variants rather than dedicated APG-grade roots. Before promotion, the family still needs broader submenu pointer-intent evidence, nested dismissal/focus-restoration coverage, RTL behavior, and a decision on whether navigation menu gets a dedicated viewport/link-content behavior path instead of remaining a menubar-shaped alias.
