# 0.2 UI App Layer Preview Tracker

## Parent

[#291](https://github.com/erik-kroon/keystone-ui/issues/291) is the 0.2 UI app-layer preview parent. Do not select 0.2 work by scanning the full backlog; use this tracker and the linked vertical docs as the board.

0.2 proves Keystone UI as source-owned app-layer code on top of Core primitives, with TanStack-native integrations where they are the right engine. The preview is intentionally narrower than the end-state inventory.

## Verification Gate

Run `bun run verify:example-app` before marking the preview shipped. The script installs the preview registry items into a generated Solid Vite fixture, verifies SSR output for app-layer source, runs `check-types`, and builds the app.

The 2026-05-05 sequencing update on #291 still applies: 0.1 evidence work gates further app-layer expansion. Do not pull 0.3 data-dense workspace items forward until that gate is closed or explicitly waived.
